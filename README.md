# ConvertPDF Desktop Downloads

Official distribution channel for ConvertPDF desktop installers.

- Website: https://convertpdf.ro
- Downloads: https://github.com/csivpunctro/convertpdf-downloads/releases

## Download and verify

Download an installer only from the GitHub Releases page in this repository. When a release includes `SHA256SUMS.txt`, verify the downloaded files from the directory containing the checksum file:

```bash
sha256sum -c SHA256SUMS.txt
```

A checksum confirms file integrity against the published release checksum. It does not independently prove who built the installer.

## Platform availability

Only installers explicitly attached to a published release are available. A platform is not supported by this download channel until its installer appears in the release assets.
